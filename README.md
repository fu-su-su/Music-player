# Music Player 使用说明

一款本地音乐播放器 Android 应用,支持播放、歌词、歌单、主题换肤,并内置 AI 助手,可直接用自然语言指挥播放器。

 安装

1. 获得 APK 文件(`app-debug.apk` 或发布版 APK)
2. 在手机上打开该 APK,如提示"未知来源应用",允许安装即可
3. 系统要求:Android 6.0(API 23)及以上

 权限说明

首次启动会依次引导授权,各权限用途如下:

| 权限 | 用途 |
|---|---|
| 音频/图片媒体权限 | 扫描手机里的音乐文件和封面图片 |
| 通知权限 | 播放时在通知栏显示控制按钮 |
| 其他 | 应用数据保存在自己的私有目录,不会读取你的其他文件 |

 快速上手

1. 导入音乐:主页点右上角齿轮 → 设置面板 → 「导入音乐」(选文件)或「扫描设备音乐」(自动扫描全机)
2. 播放:点击列表中的歌曲即可播放,再次点击进入播放页
3. 播放页:上下曲切换、进度拖动、循环模式(顺序/单曲/随机)、歌词滚动
4. 后台播放:退出界面后音乐继续,可通过通知栏或锁屏控制

 功能一览

- 歌词显示:配合 `.lrc` 文件自动逐行高亮滚动
- 批量匹配:设置面板中一键为所有歌曲匹配歌词和封面图片
- 歌单:创建/重命名/删除歌单,把歌曲加入不同歌单
- 搜索:主页搜索框按歌名/歌手模糊搜索
- 睡眠定时:15 / 30 / 60 分钟或播完当前歌曲后自动暂停
- AI 助手:主页 AI 图标进入对话页
- 个性化:4 套主题色(绿/蓝/紫/粉)、夜间模式、简中/繁中/英语/日语切换、歌词字号三档、为单曲设置专属播放页背景

 常见问题

Q:扫描不到设备音乐?
确认已在系统设置中授予音频媒体权限;部分手机需允许"所有文件访问"或把音乐放到 `Music` 文件夹。

Q:歌词不显示?
把与歌曲同名的 `.lrc` 文件放入应用的 `lyrics` 目录,或使用设置面板的"自动匹配歌词"。

Q:封面显示不对?
使用"自动匹配图片"批量重新匹配,匹配不到时封面为默认图。

Q:应用数据在手机哪里?
存放在 `Android/data/com.musicplayer.app/files/` 下的 `music`、`covers`、`lyrics` 目录,卸载应用会一并删除,请提前备份。

 注意

- AI 助手联网调用(智谱 GLM-4-Flash),无需额外配置
- 卸载或清除数据会删除应用内导入的音乐文件,重要音频请保留原文件
- app接受各形式音频文件，首先要下载到本地，才能被识别到
- 后续会接入网络搜索\下载歌曲文件功能
