🎵 Music Player 使用说明
一款本地音乐播放器 Android 应用，支持播放、歌词、歌单、主题换肤，并内置 AI 智能助手（Agent）。
你可以直接用自然语言指挥播放器，也能为每首歌单独定制播放背景，打造专属听歌体验。

🤖 AI Agent：用聊天代替点按
主页点击 AI 图标进入对话页，你可以像和朋友说话一样控制播放器：

“播放歌曲——Flower Dance”

“删除歌曲”

“把这首歌加入我的跑步歌单”

“15 分钟后暂停”

“切换到紫色主题”

Agent 能力：基于智谱 GLM-4-Flash 模型，无需额外配置，开箱即用。

注意：使用作者提供的 API 额度，额度用尽后 AI 服务将关停。请勿恶意拉取。

🖼️ 播放背景：每首歌都可以不一样
在播放页可以为当前歌曲 单独设置背景图片，让每首歌都有专属视觉氛围。
支持从相册选择或直接拍照，设置后该歌曲再次播放时自动加载对应背景。

📦 安装与权限
获取 APK 文件并安装（需允许未知来源应用）

系统要求：Android 6.0（API 23）及以上

首次启动会引导授权，权限说明如下：

权限	用途
音频/图片媒体权限	扫描手机中的音乐文件和封面图片
通知权限	播放时在通知栏显示控制按钮
其他	数据仅保存在应用私有目录，不会读取其他文件
🚀 快速上手
导入音乐：主页右上角齿轮 → 设置面板 → 「导入音乐」选文件，或「扫描设备音乐」自动搜索全机

播放：点击列表歌曲即播放，再次点击进入播放页

播放页操作：上下曲切换、进度拖动、循环模式（顺序/单曲/随机）、歌词滚动

后台播放：退出界面后音乐继续，通知栏/锁屏可控制

📋 功能一览
歌词显示：配合 .lrc 文件自动逐行高亮滚动

批量匹配：设置面板一键为所有歌曲匹配歌词和封面

歌单管理：创建/重命名/删除歌单，歌曲可加入多个歌单

搜索：主页搜索框按歌名/歌手模糊搜索

睡眠定时：15/30/60 分钟或播完当前歌曲后自动暂停

AI 助手：自然语言控制播放器

个性化：

4 套主题色（绿/蓝/紫/粉）

夜间模式

简中/繁中/英语/日语切换

❓ 常见问题
Q：扫描不到设备音乐？
确认已授予音频媒体权限；部分手机需允许“所有文件访问”，或把音乐放到 Music 文件夹。

Q：歌词不显示？
将同名 .lrc 文件放入应用的 lyrics 目录，或使用设置面板的“自动匹配歌词”。

Q：封面显示不对？
使用“自动匹配图片”批量重新匹配，匹配不到时显示默认封面。

Q：应用数据存在哪里？
路径：Android/data/com.musicplayer.app/files/ 下的 music、covers、lyrics 目录。
卸载应用会一并删除，重要文件请提前备份。

⚠️ 注意
AI 助手使用作者本人 API Key（明文提供），请勿恶意拉取

卸载或清除数据会删除应用内导入的音乐文件，请保留原文件备份

应用接受各形式音频文件，需先下载到本地才能被识别

后续将接入网络搜索/下载歌曲功能
